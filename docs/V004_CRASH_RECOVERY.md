# Launcher v0.0.4: healthy 이후 충돌 복구

- v0.0.3 UI, 고정 배경, 애니메이션, 설정 파일 변경 없음(버전 표기만 v0.0.4).
- 대기 호스트가 런처 종료 코드를 관찰해 healthy 이후 비정상 종료(0 아닌 종료 코드) 시 이전 런처 버전으로 전환. 자동 재실행은 하지 않음.
- healthy 이전 시작 오류는 기존 pending 복구 경로 유지. 정상 종료는 롤백 안 함.
- 버전 변경 또는 새로운 세션이 있으면 오래된 세션의 롤백은 무시.
- Windows CI와 격리된 테스트를 통과한 동일 source SHA의 ZIP만 Release한다.
- 기존 호스트는 원격 런처 ZIP에 포함되지 않음. 최초 한 번 별도 host-transition 패키지 적용 필요. 0.0.1(레거시/기존) 및 v0.0.3 호스트 SHA를 검증하며, 기록·설정·배경은 수정하지 않음.
- 모든 강제 전원 차단/윈도우 예외/프로세스 exit 0 문제를 해결한다는 뜻이 아님.
- 로컬 개발 테스트만으로 Windows 실사용 검증 성공을 주장하지 않음.
